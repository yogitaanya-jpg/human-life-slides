## 🎨 Visual Design System (Style A)

- **Aesthetic**: *Monocle* editorial magazine meets literary essay.
- **Typography**: Editorial serifs (*Playfair Display* & *Noto Serif SC*) paired with clean sans-serif body text and monospace metadata.
- **Color Palette**: 🍂 **Kraft Paper (牛皮纸)** — Warm walnut ink (`#2a1e13`) on amber-cream parchment (`#eedfc7`).
- **WebGL Shaders**: Dual GPU canvas shaders (*Holographic Dispersion* on dark slides, *Spiral Vortex* on light slides).
- **Rhythm**: Dynamic 8-slide cadence alternating between dark and light themes without visual fatigue.

## 🎮 Presentation Controls

| Key / Action | Function |
|---|---|
| `←` / `→` or `Space` | Next / Previous slide |
| `P` | **Presenter Mode** (dual-window audience view, speaker notes, rehearsal timer) |
| `ESC` | **Overview Matrix** (thumbnail grid navigator) |
| `B` | **Low-Power Mode** (toggle off canvas/WebGL animations) |
| Mouse Wheel / Touch | Swipe to advance slides |
